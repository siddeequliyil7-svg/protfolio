## 🛠️ Tech Stack & Architecture
- **Framework & UI:** React.js (Single Page Application)
- **Styling:** Modern Dark Mode & Tailwind CSS with Glassmorphism & Neon Glow effects
- **Typography:** Google Fonts (Syne, Outfit, Plus Jakarta Sans, JetBrains Mono)
- **Build Tool:** Vite Bundler
- **Hosting & CI/CD:** Vercel (Auto-deploys on `git push origin main`)
- **Version Control:** Git & GitHub

---

## 📁 Project Structure
- `index.html` - Main HTML5 entry point with OpenGraph SEO & metadata tags.
- `assets/` - Compiled and optimized React application bundles & CSS styles.
